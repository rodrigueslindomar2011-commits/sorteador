# 🎲 Sorteador

Um projeto simples e funcional para realizar sorteios de números de forma rápida, prática e aleatória.

## 📌 Sobre o projeto

O Sorteador permite que o usuário defina:

- Número mínimo
- Número máximo
- Quantidade de números que deseja sortear

O sistema realiza o sorteio automaticamente e apresenta os resultados na tela.

## 🚀 Funcionalidades

- Sorteio de números aleatórios
- Validação dos campos
- Não permite números repetidos
- Controle da quantidade de números sorteados
- Mensagens de erro
- Interface responsiva
- Animação na apresentação dos resultados

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Google Fonts
